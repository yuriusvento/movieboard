# Movieboard — «Линия огня»

Интерактивная сценовая доска фильма «Линия огня», собранная из канонической редакции версии 6.

## Возможности

- 22 исходные карточки без изменения содержания;
- перетаскивание мышью и касанием;
- перестановка с клавиатуры стрелками на ручке карточки;
- добавление, редактирование, дублирование и удаление сцен;
- автоматическая перенумерация;
- цветовые метки и рабочие заметки;
- поиск и компактный режим;
- автосохранение в браузере;
- отмена и повтор изменений;
- экспорт и импорт доски в JSON;
- экспорт сцен в текст.

Откройте `index.html` локально или включите GitHub Pages для ветки `main`.
